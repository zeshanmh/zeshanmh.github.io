# Academic Website Revamp Goals

This is my personal academic website. The goal is to make it modern, polished, and research-forward.

Priorities:
- Update publications and selected work.
- Rewrite homepage/research text to be more compelling and aligned with my most recent research.
- Improve publication cards, especially icons/thumbnails.
- Make icons visually consistent, appropriately sized, and optionally animated GIFs where useful.
- Modernize the layout and visual style, inspired by https://demireal.github.io/ but not copied.
- Preserve academic clarity, fast loading, accessibility, and mobile responsiveness.

Style direction:
- Clean academic homepage.
- Strong “about / research / selected work / news” structure.
- Modern typography, generous spacing, compact publication cards.
- Avoid flashy startup-site aesthetics.
